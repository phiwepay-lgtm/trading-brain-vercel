Algo V1 MT5 research package — uncompiled and unverified

Copy the MQL5 folder into the MT5 data folder, then compile the indicator and tester EA in MetaEditor. The Include file is required.

Only standard M1 is supported. Tester EA orders are disabled by default and cannot run on live or demo accounts. This is an approximation of discretionary rules, not a verified implementation or evidence of profitable results. Test historical events, gap handling, quotes, spread and breakeven on the intended feed before interpreting results. See the EA Center research notes for full assumptions and limitations.
